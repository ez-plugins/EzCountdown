# Features

Detailed documentation for each feature in EzCountdown.

## What's in this section

| Page | Description |
|---|---|
| [Countdown Types](countdown_types) | Fixed date, duration, manual, recurring, and clock-aligned modes |
| [Display Types](display/) | Action bar, boss bar, title, chat, scoreboard, and dialog (Paper 1.21.7+) |
| [Firework Shows](firework_shows) | Trigger firework displays on countdown start or end |
| [GUI](gui) | In-game visual editor for managing countdowns |
| [Placeholders](placeholders) | PlaceholderAPI placeholders for use in other plugins |
| [Teleport](teleport) | Teleport players to named locations on start or end |
| [Timezones](timezones) | IANA timezone reference for clock-aligned recurring countdowns |
| [Discord Integration](discord_integration) | Post webhook notifications to Discord |

## Compatibility quick reference

| Feature | Min. Minecraft version |
|---|---|
| Core (action bar, chat, title) | Paper/Spigot 1.18 |
| Boss bar | Paper/Spigot 1.18 (Bukkit boss bar API, available since MC 1.9) |
| Scoreboard | Paper/Spigot 1.18 |
| Dialog display | Paper 1.21.7+  -  gracefully skipped on older builds |
| PlaceholderAPI | Any 1.18+ build with PlaceholderAPI installed |
| Clock-aligned recurring | Paper/Spigot 1.18 |
