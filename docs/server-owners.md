# Server Owners

This section covers everything you need to run EzCountdown on your server without writing any code.

## Installation

1. Download the latest jar from [GitHub Releases](https://github.com/ez-plugins/EzCountdown/releases).
2. Place the jar in your server's `plugins/` folder.
3. Start or restart the server. Configuration files are created automatically inside `plugins/EzCountdown/`.

**Requirements:** Paper or Spigot 1.18 (or any fork) and Java 17.
